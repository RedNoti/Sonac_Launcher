화면배치와 조작
첫 실행중앙 단계 카드. 환영 → NAS만·서버 업데이터만·둘 다 선택 → 계정 연결 → 완료. 둘 다 선택하면 계정 연결 단계가 두 번 표시됩니다. 하단 단계 점과 이동 버튼.
시작 · NAS 로그인왼쪽에 SONAC LAUNCHER 로고, 저장소·Synology 추가·서버 업데이터 타일. 오른쪽에 선택한 NAS 로그인 또는 NAS 등록·수정. 등록·수정 양식은 긴 입력 항목에 맞춰 오른쪽에서 세로 중앙 배치. 우측 상단 업데이트·설정, 하단 오른쪽에 버전.
시작 · 서버 업데이터시작 화면의 왼쪽 타일을 사용합니다. 오른쪽 패널은 서비스 상태와 서버 업데이터 로그인 사이에서 전환됩니다. 로그인 화면 제목과 왼쪽 로고가 뷰 변경 중 갑자기 재배치되지 않도록 오른쪽 패널만 움직입니다.
NAS 홈상단에 워드마크와 동기화·설정 등 계정 도구. 가운데 그룹별 앱 아이콘, 아래에 동기화 파일과 영역 추가 버튼. 넓은 창에서 그룹은 6열 격자를 사용하고 2개 타일 그룹은 2열을 차지합니다.
파일 스테이션 · 폴더 선택왼쪽 탐색과 즐겨찾기, 오른쪽에 경로 표시·상위 폴더·새로고침·업로드, 선택 작업 도구 모음, 목록/격자와 하단 항목 수. 우클릭 메뉴에서 사용 가능한 선택 작업을 다시 제공합니다. 폴더 선택 모드에서는 파일 작업 대신 현재 폴더를 선택합니다.

백업 · 동기화홈에 폴더 아이콘과 동기화 영역을 표시. 그룹을 열면 내부 항목을 격자로 표시합니다. 그룹 추가·편집, 동기화 항목 추가·수정, NAS·로컬 폴더 선택은 각각의 대화상자에서 처리합니다.
GitHub상단 계정·연결 제어, 본문 프로젝트 선택과 등록된 프로젝트 목록. 프로젝트별 GitHub 열기와 연결 관리.
서버 업데이터 홈헤더에 계정과 홈·설정·로그아웃. 서버·터미널·AI 타일을 중앙에 배치하고 프로젝트가 늘면 줄바꿈합니다. 아래 실행 서버·운영 웹페이지·마지막 업데이트 요약, 배포 프로젝트, 운영 중인 웹페이지 목록/격자.
서버 프로젝트카드에 프로젝트명, 상태, 버전과 출처 표시. 업데이트 버튼과 재생·정지·로그·GitHub 아이콘, 추가 작업 메뉴. GitHub 연결과 릴리스 ZIP 선택은 대화상자로 엽니다.
터미널상단 제목과 창 도구, 그 아래 세션 탭, 본문 터미널 카드. 명령 모음은 팝오버로 열리며 명령·관리 버튼을 제공합니다.

설정왼쪽 탐색, 오른쪽 섹션. 계정 및 연결, 런처, 미디어, 백업·동기화. 런처 업데이트 상태와 진행률은 앱 버전 옆 버튼에 표시됩니다. 기본 영상·음악 폴더 변경은 미디어 설정에서 합니다.

반응형과 접근성

  • 700px 이하에서는 시작 화면이 한 열이 되고, 파일 스테이션 탐색과 AI 대화 목록이 위쪽으로 이동합니다.
  • 760px 이하에서는 영상 플레이어와 폴더 목록을 한 열로 쌓습니다. 서버 요약 카드는 650px 이하에서 한 열입니다.
  • NAS 홈은 1120px 이상에서 그룹용 6열, 음악 패널은 1000px 이상에서 본문 여백을 확보합니다.
  • prefers-reduced-motion에서 CSS 애니메이션·전환을 끄고, JS의 페이지·로그인·첫 실행 애니메이션도 건너뜁니다. 로딩 문구, 선택 상태, 진행 숫자는 표시됩니다.
  • 주요 아이콘에는 이름이나 툴팁을 붙입니다. 선택과 패널 열림 여부는 aria-pressed, aria-expanded로 전달합니다. 숨겨진 영역은 필요한 경우 inert로 상호작용을 막습니다.
  • HTML의 모션 샘플은 화면 구성과 동작 기록을 위한 축소 예시입니다. NAS 로그인, 영상 재생, 업데이트 연결은 실제 앱에서 실행합니다.
