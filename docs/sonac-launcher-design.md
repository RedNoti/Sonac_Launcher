# SONAC LAUNCHER 디자인 · 레이아웃 · 모션
기준은 표시 버전 a0.3.9.3 이후의 작업 트리입니다. NAS ZIP 압축 풀기 옵션, 중계 서버를 사용하는 AI, 폴더별 영상 목록과 대용량 영상 재생 변경을 포함합니다.

## 모션 레퍼런스
시간은 현재 코드의 설정값입니다. `page`는 `cubic-bezier(.22,1,.36,1)`, `spring`은 `cubic-bezier(.34,1.56,.64,1)`을 뜻합니다.

| 대상 | 동작 | 시간과 보간 |
| --- | --- | --- |
| 일반 버튼·스위치 | 배경/텍스트/테두리 전환, 눌렀을 때 버튼 0.96배, 스위치 손잡이 이동 | 150ms ease-out |
| 홈 타일 | 아래 14px·투명·0.6배에서 등장. 타일별 시차와 페이지 진입 시차를 합산 | 600ms spring |
| 타일 호버·누름 | 위로 6px와 1.04배, 내부 아이콘 1.1배. 누르면 타일 0.96배 | 호버 450ms spring, 누름 120ms |
| 선택된 NAS 타일 | 푸른 테두리가 투명·0.88배에서 등장 | 400ms spring |

## 반응형과 접근성
- 700px 이하에서는 시작 화면이 한 열이 되고, 파일 스테이션 탐색과 AI 대화 목록이 위쪽으로 이동합니다.
- 760px 이하에서는 영상 플레이어와 폴더 목록을 한 열로 쌓습니다. 서버 요약 카드는 650px 이하에서 한 열입니다.
- NAS 홈은 1120px 이상에서 그룹용 6열, 음악 패널은 1000px 이상에서 본문 여백을 확보합니다.
- `prefers-reduced-motion`에서 CSS 애니메이션·전환을 끄고, JS의 페이지·로그인·첫 실행 애니메이션도 건너뜁니다. 로딩 문구, 선택 상태, 진행 숫자는 표시됩니다.
- 주요 아이콘에는 이름이나 툴팁을 붙입니다. 선택과 패널 열림 여부는 `aria-pressed`, `aria-expanded`로 전달합니다. 숨겨진 영역은 필요한 경우 `inert`로 상호작용을 막습니다.
- HTML의 모션 샘플은 화면 구성과 동작 기록을 위한 축소 예시입니다. NAS 로그인, 영상 재생, 업데이트 연결은 실제 앱에서 실행합니다.
